# 双端更新接入与验收（0.8.5 / 135 本机候选）

阶段80新增操作流程见[更新交付操作](更新交付操作.md)。0.8.9/141记录安装尝试，并用重启后的实际构建码确认结果；Windows与Android都不将启动系统安装器当作安装成功。发布目录与签名服务适配已准备，真实证书、更新源与生产清单密钥仍待提供；当前140缺少信任根，需要首个配置过的版本手动引导一次。

## 实现与默认行为

- 双端设置 → 版本与更新。自动检查默认开启、12小时一次；自动下载默认关闭。启动15秒后空闲检查，手动检查不受周期限制。
- 自动下载仅在非计费网络、没有已知串流或文件任务时开始。无法判断网络成本时只允许用户手动下载。下载有进度、取消和重新下载，不弹安装确认。
- Android使用系统JobScheduler做应用关闭后的周期检查，持久化跨重启；系统省电策略可推迟运行，强制停止应用会暂停至再次打开。检查失败后在系统允许时退避重试。
- Windows托盘进程运行时检查，真正退出界面后停止。Windows更新偏好与主题、绑定分开保存；Android独立SharedPreferences。下载记录跨重启保留，恢复时重新验签及校验文件。
- 安装始终由用户点“安装更新”。Windows服务再次取得维护锁，未完成的文件任务或活动会话阻止安装；Android安装前核对正在准备、串流、文件服务。下载后没有无人确认的强制安装。
- Windows仍须UAC。Android首次需在系统允许“我控制”安装应用，返回后再次点安装；覆盖升级还需系统安装确认。安装失败/取消保留当前应用和设置，不卸载重装。
- Windows复用受保护的升级备份及失败恢复，保留“恢复上个版本”。Android没有实现安装后版本降级回滚；失败/取消通常保留当前版，不能把它宣传为完整回滚。

## 发布源与信任配置

当前没有真实发布站点或Windows证书。仓库的Windows/Android生产feed与公钥保持空值，界面明确提示“更新发布源尚未接入”，不会请求示例域名或下载安装测试包。所有本机测试密钥仅用于测试，不能进入生产信任配置。

使用同一HTTPS域名的静态发布源，无需自建账号服务。目录示例：

```
/internal/windows.json     # Windows签名清单
/internal/android.json     # Android签名清单
/packages/135/windows.exe
/packages/135/android.apk
```

同源必须直接返回200和完整数据；不使用登录、跨域CDN或跳转下载。当前禁止重定向，不能直接假定GitHub Releases下载链接可用。上传次序为先不可变安装包，再原子替换清单；清单建议no-cache、包可长缓存。

取得实际站点与RSA3072或以上的SPKI公钥后，运行scripts/Configure-UpdateTrust.ps1，填WindowsFeed、AndroidFeed、ManifestPublicKey及可选WindowsPublisherSha256。可先用ValidateOnly验证格式；该脚本不部署站点、不注册账号、不生成私钥。

接入前后可运行 `scripts/Test-UpdateReadiness.ps1 -SourceRoot <源码目录> -Output <报告.json>`，一次列出双端 feed、公钥、Windows 发布者白名单的缺项，并区分“可以查询”和“可以下载安装”。脚本只读本机配置，不生成密钥、不访问站点；示例/测试域名不会算作真实发布源。`-RequireQueryReady` 可作为构建前置检查。即使格式就绪，仍需真实 HTTPS 访问和线上升级验收；不能把报告的 configured 当作证书或包已验签。

公钥随包内置，私钥在源码、构建与发布目录外独立保管。清单使用SHA256-PSS、MGF1-SHA256、32字节salt，最长90天；不可跨渠道、降版、换产品或架构。清单和包必须同HTTPS来源。过期、超限、错误哈希、错误签名均拒绝。

## 无Windows证书时

Windows查询只要求HTTPS feed与清单公钥；下载/安装仍要求受信Authenticode证书及内置发布者指纹。Create-UpdateManifest.ps1的QueryOnly显式生成仅供版本提示的Windows清单，只有publisherSha256为空才能使用；不允许借此跳过安装校验。有证书后重建带指纹的客户端，才启用在线下载安装。

Android继续原包名com.streamhub.client与原发布证书。Create-UpdateManifest.ps1使用Platform android，并明确提供AndroidCertificateSha256；脚本调用apksigner与aapt2核对签名、包名及版本。运行时再次核对当前已装证书、目标版本和SHA256，最后交给系统安装器。

ManifestPrivateKey、Installer、PackageUrl、Output、NotesFile为清单生成必填参数，默认读取唯一版本源。输出是本机文件，脚本不上传。当前候选未启用任何临时签名站点；准备接入不等于线上更新已验收。

## 后续集中安装时的验收范围

1. 双端更新入口、三态（最新/新版本/失败）、自动检查开关持久化、浅深色与横竖屏的新增区域。
2. 旧→新升级，保留绑定、主题、通道；取消系统授权后仍可重试。
3. 清单或安装包篡改拒绝，跨渠道/降版/过期拒绝，断网取消后重试；缓存恢复时重验。
4. 串流及文件任务进行中拒绝安装；结束任务后可安装。自动检查/下载不触发UAC或Android安装页面。
5. Windows安装失败恢复及“恢复上个版本”；Android错误签名拒绝和失败/取消保留原应用。

只验证本轮更新相关行为，不重跑未修改UI、帧率、冷启动或隐私屏专项。线上端到端仍需真实发布源、发布密钥，以及Windows可信签名条件。
