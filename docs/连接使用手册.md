# 连接使用手册

电脑点“+ 绑定设备”，安卓点“+ 添加电脑”，选择附近电脑并输入**六位短码**。短码三分钟有效；核对两端校验码后，在电脑确认。完整绑定码仍可在“高级”中复制。高级兼容接收端使用的四位媒体 PIN 是另一种配对流程。

同一网络直接连接。异地使用前，两端选择同一通道并完成登录，再验证一次实际连接。发现广播不通时，可填写电脑地址；地址可达仍是前提。

安卓首页点“远程控制”或“用作扩展屏”。由电脑发起副屏时，先在安卓设置开启接收请求，再点电脑顶栏“副屏”并选择设备。

电脑在设备“权限”中开启文件功能，选择目录并允许设备。安卓“文件”页直接浏览、下载或发送本机文件。保存目录由系统选择器授权，后续下载复用；目录失效时重新选择。上传和删除分别授权，清理传输记录不会删除源文件。

实体键盘用 Ctrl+Alt+Tab 切换电脑窗口。可选“系统快捷键”默认关闭，需要在安卓设置里手动授权辅助功能；只在远控前台转发 Alt+Tab（含 Shift 反向）及 Win 键，不读取界面内容或记录按键。Win 键从按下到松开都发给电脑，普通按键沿用原输入路径。部分系统可能仍保留快捷键，届时使用软菜单或 Ctrl+Alt+Tab。按住 Alt 时，Tab 继续轮选、Shift 反向，松开 Alt 确认；失焦、退出或关闭功能会释放电脑上的 Alt 和 Win。Win+Tab 打开电脑任务视图，松开后仍保留列表，可用鼠标或方向键选择。

电脑顶栏“断开连接”只结束本次主屏和副屏连接，电脑仍接受连接。“断开并暂停连接”会断开当前主屏和副屏，并阻止重新连接；重启后仍保持暂停，需在电脑顶栏手动恢复。有活动会话时，暂停前会再次确认，默认选择“否”。Ctrl+Alt+F12 恢复隐私屏。远控引擎持续45秒未就绪时，状态会显示原因入口；暂停、恢复或重启服务后重新计时，自动重试进程不会无限重置等待。
