# CodeQL告警整改与边界审阅

基线为公开提交`35277706a14c9e51648460144129d7cad1aee26b`（160完整源码及文档/CI补充）。[扫描](https://github.com/xDawn114/streamhub/actions/runs/43673674397)成功生成并上传Windows C#和Android Java分析，发现18条告警。本轮不通过删除规则、全局忽略或自动关闭告警追求清零；以下是源码审阅及本机整改，不替代完整渗透测试。

| 告警编号 | 位置与判断 | 处理和保留的边界 |
| --- | --- | --- |
| 18 | `SeekBarPreference`的进度与持久值运算可能溢出 | 检查资源范围、步长和除数，持久值限界，舍入先用long再限制到有效区间；非法配置拒绝初始化 |
| 17、13 | `HelpActivity`允许脚本及content访问 | 关闭JavaScript、文件/content访问、file跨源与混合内容；初始地址和导航只接受合法HTTPS，销毁时释放WebView。链接策略含正常及file/content/javascript/HTTP等拒绝用例 |
| 16 | `LimeLog`可能写入来自对端的多行内容 | 统一替换CR/LF、NEL和Unicode行/段分隔符，阻止伪造下一条日志；正常中文及消息内容保留 |
| 10 | `HubSessionLease`检查后异步回执可能写到下一次画面 | 原子捕获待报告代次；回执只能标记同代已建立媒体连接。测试覆盖旧回执晚到与新代未就绪 |
| 9 | `ComputerManagerService`网络探测异常可能遗留锁与路由 | try/finally恢复临时网络绑定，嵌套finally保证释放锁；不修改系统VPN配置 |
| 8 | `HubControlClient`直连目标被标为SSRF | 这是Android控制端主动访问用户绑定的电脑，不是服务器代发请求。保留绑定码证书SHA-256固定、有效期和Bearer验证；追加禁止HTTP/HTTPS跳转，避免请求被带往其他目标。绑定资料泄漏或恶意绑定仍是实际风险，不能凭客户端用途忽略它 |
| 15 | `HubUpdates`调用Android安装器，被标为任意APK安装 | 保留预期更新能力供审阅：包来自RSA-PSS清单指定的同源HTTPS地址，验证大小/hash/包名/版本/当前应用原签名，放私有updates目录；安装前重验，仅在用户操作后交给系统确认。不能安装任意文件或绕过Android授权；尚无生产源的端到端升级验收 |
| 14 | `HubActivity`账号与地址显示被标为敏感文本 | 默认遮盖，用户点按才显示本人连接详情，并提供再次隐藏。此处是显式查看，不在后台发往日志或外部站点；仍应防录屏或旁观泄露 |
| 12 | `HubUpdatePolicy`的RSASSA-PSS被泛化标为弱算法 | 保留RSA不少于3072位、SHA-256、MGF1 SHA-256与32字节salt的明确参数，失败拒绝清单。不是SHA-1签名；不为消除告警更换已跨端核对的协议 |
| 11 | `PairingManager`保留旧GameStream协议SHA-1 | 服务代次7及以上使用SHA-256；低于7的旧主机兼容分支仍使用SHA-1，本轮没有移除。iControl当前Sunshine不依赖旧分支，但不能据此声称整个接收端已无SHA-1。待独立兼容决策后再缩小遗留支持 |
| 7、6 | `TrackpadContext`double精度倍率复合赋值为float | 触控位移乘精度倍率后交给原有float输入路径；Java复合赋值本就显式定义该窄化语义。当前未取得可利用边界证据，保留告警，不用等价强转掩盖 |
| 5 | `Game.getRotationDegrees`的short角度加360 | 正常设备方向转换后范围可由short承载，未发现该行造成认证或权限绕过。保留告警；异常设备输入的全链限界未在此声称验证 |
| 4、3、2、1 | `ControlApiServer`按用户路径选路由被标为鉴权绕过 | 非绑定路由首先统一拒绝未认证请求；文件/剪贴板/远控/副屏随后检查scope与client；准备任务、历史任务读取与会话续期各有`AuthorizePrepare`、`AuthorizeJob`、`EnsureCurrent`。隔离边界与逐设备撤权检查实际运行；未因路径分派删掉权限验证 |

本机更新交付边界检查70项、发布目录兼容/拒绝检查14项通过。Android定向检查覆盖帮助链接、日志分隔符、会话代次与更新策略。公开CI将对追加提交重新执行；以那个提交的实际结果判断告警是否被分析器识别为已修复，不把这张表当作平台关闭状态。

C++、JNI、Go和预编译输入不因上述Java/C#结果获得覆盖。原生缓存策略有独立C++检查及完整编译，尚无C++ CodeQL数据库。发现可利用问题仍使用[私密披露渠道](../SECURITY.md)，不公开利用细节。
