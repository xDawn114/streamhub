# 功能保留与迁移清单

2026-11-18。维护者确认“审查中值得采用的改进与上游有用功能两部分都纳入，按影响操作的程度先后改”。本轮在179基础上修改本机文件，版本号未变；本页的“本机已补”不代表已经装到电脑或平板。

## 统一规则

- 自研一级、二级页面使用同一套标题/返回、宽度、字体与深浅主题；兼容协议功能保留自己的数据库与信任，不切换产品绑定。
- 产品文案统一“副屏”“平板”；连接方式只用Tailscale、自建、局域网/USB、手动，配置方式与实际目的地址分别呈现。
- 开关/单选即时保存，失败反馈并恢复确认值；输入框使用保存按钮。下次连接设置不在串流中升档。
- 主按钮实心蓝、次按钮中性底/描边、文字按钮、危险按钮；不可用文字保持可读，危险操作确认。
- 一级页面骨架固定；串流固定操作行和滚动区分开，旋转、键盘及小窗不截断关键操作。

## 保留的原有优点

快捷键文字网格、长按置顶、修饰键组合、中文文本、完整键盘、手动剪贴板、性能数据、诊断和原始采样、分辨率/帧率/实际路径、缩放与平移、隐私屏、锁屏与退出、USB网络共享、两端发起副屏、逐设备文件权限、断开二次确认、quitApp正常退出收尾均保留。第三方实现、许可和旧配置档不删除。

厂商型号限定开关、Apollo品牌文案、对产品无效的虚拟显示器编辑没有重新放回产品入口。远程开机、终端、缓存壁纸的云同步等不因UU截图出现就新增；本轮使用的预览是上次串流本机快照。

## 验证边界

Android Java/资源编译、定向隔离行为用例及深浅/横竖/IME渲染；Windows Release编译、设置提交/回退与布局检查。本轮不构建APK/安装器、不安装、不修改用户真实网络/安全/账号/绑定、不作性能采样。

配对TLS、真机PixelCopy预览、实际静音/手柄/键盘/HDR/系统PiP、断线后真实状态时序仍需下次安装后定向验证。签名、公开源码、在线更新和0点击交付问题独立记录，不能以界面完成代替交付通过。逐条审查映射见[UI建议落实映射](UI建议落实映射-2026-11-18.md)。
