# 手机远控：调整视图

0.8.13/153 本机源码追加功能，手机和平板共用；暂未安装。

入口：远控中打开“控制 → 画面 → 调整视图（暂停触控）”。打开后会收起键盘和主控制菜单，显示可以拖动的调整条。

- 单指拖动画面，双指缩放，范围100%～400%；也可用“− / ＋”按钮调整。
- 调整期间点击、长按、双指和触控笔事件只用于本机画面，不发送电脑点击、原生触摸或滚动；切换时清理旧触摸状态，并等待新的按下，防止手势尾部变成误点。
- “完成”保留当前倍率和画面位置，恢复触屏远控，再点击放大的小按钮。Android返回键也先完成调整，不直接退出远控。
- “还原”恢复完整画面至100%，仍停在调整模式；主控制菜单也提供还原入口。
- 调整条显示当前倍率与“单指拖动 · 双指缩放 · 不操作电脑”，拖动其标题区可以避开目标。横竖屏或窗口变化后重新限制画面与调整条位置。

只放大本机显示，不更改电脑分辨率、编码或远程桌面缩放。调整开关默认关闭；完成调整后的画面位置在当前会话保留，跨会话行为沿用原有“记住缩放/平移”偏好，不自动开启。

鼠标兼容触控与原生触摸都按放大后的内容坐标映射。直接送到SurfaceView的事件已经由Android逆变换，不再次换算；背景区域事件才按视图位置和倍率计算。手势识别使用父容器坐标，避免放大倍数影响拖动速度。

本机Robolectric真实Game事件入口、模拟连接和原生UI共11项检查及正式变体Java/资源编译通过；尚未构建APK或验收真实SurfaceView视频、物理双指手感。下次安装仅补开启/误触、缩放/拖动、完成后点击小按钮、还原、横竖屏与调整条避让，不重测音频、网络、文件或其他未改业务。
