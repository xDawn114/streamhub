# 双端界面规则

适用于本机 0.8.37/179 起的产品页面。协议字段、系统设置名称及第三方许可保留原名。

## 页面与返回

- 一级页面共用标题字号、左右留白和内容最大宽度；平板为 720dp，窄屏按可用宽度收缩。
- 二级页面使用自研标题和返回按钮；系统返回先返回上一级。产品设置不跳转上游设置或兼容主机列表。
- 文件页标题、工具栏、状态栏和标签栏保持位置；某个标签页不能使用的操作置灰，给出原因。
- 更多菜单锚定入口；必要的操作结果在当前页面或当前弹窗内显示。

## 词表

| 概念 | 界面用词 | 边界 |
| --- | --- | --- |
| 电脑第二块屏幕 | 副屏 | 不再与“扩展屏”混用 |
| 平板接收端 | 平板 | 明确识别为手机的设备卡片仍显示“手机”；未知类型用“设备” |
| 官方账号组网 | Tailscale | 不写“Tailscale 官方” |
| 自建账号组网 | 自建 | 服务区地址输入仍明确要求 HTTPS |
| 同一网络或 USB 共享 | 局域网/USB | 不以单个私网 IP 猜测 Wi-Fi/USB |
| 指定发布地址 | 手动 | 仅对已配置的手动地址作此标注 |
| 关闭未提交的弹窗 | 取消 | 执行动作用具体动词，如“保存”“删除”“切换” |

“已应用”描述保存的通道配置；首页描述已确认目的地址的实际路径。仅选择 Tailscale 不代表媒体走 Tailscale，100.x 地址本身也不证明服务方。未确认时显示“实际连接待检测”“异地地址”或“其他地址”，不捏造已生效的通道。

副屏方向以发起端为准：平板的“平板发起时的方向”用于“用作副屏”；电脑的“电脑发起时的方向”用于电脑主动请求。改默认值不切换当前会话方向，也不启动连接。

## 电脑设备卡片与账号页

- “全部设备 → 我的设备”是电脑发起副屏的唯一设备选择入口，顶栏不再另设副屏按钮或设备弹窗。手机、平板和兼容接收端使用同一个卡片模板。
- 卡片固定包含名称、设备类型、在线状态、最近联系和操作区。型号不用于猜测类型；没有可信类型的旧接收端显示“兼容设备”。不要把权限、待允许等字样拼进设备名。
- 独立绑定设备保留自己的凭据、权限、备注和详情入口。发现接收端不等于授权：只有已允许兼容连接时才显示未注册的兼容设备，并提示重新绑定。绑定列表与接收端按 ClientId 去重，已撤销记录不得通过兼容发现重新变成有效设备。
- 副屏操作在对应卡片中依次显示“连接副屏”“取消邀请”“断开副屏”，结果和失败信息留在同一卡片。活动请求暂时失去发现记录时仍保留取消或断开入口；执行前核对当前请求身份，旧卡片不能结束新请求。
- “发送文件”定位当前卡片的确切设备；权限仍由现有文件服务校验。兼容卡不展示独立凭据的权限菜单，不因发现设备而扩大权限。
- “账号与连接”仅设“连接方式”“连接状态”“账号内设备”三个分组。方式选择器直接显示当前选项，不再叠加“当前通道”等重复标题；运行状态使用正文字级，浏览器授权提示只在确有授权链接时出现。

## 保存与失败

- 开关和单选即时提交；下一次连接才使用的选项写明“下次连接生效”。
- 密码、地址、数值输入使用“保存”。输入未验证或被取消时，保留已确认的选择。
- 网络、安全策略提交期间禁用重复操作；风险确认拒绝或提交失败，恢复已确认状态并保留错误反馈。程序不得把拟提交值冒充已应用值。
- 显式切换通道可能中断异地连接，保留确认。文件传输或串流忙时拒绝切换。
- 选账号电脑只打开待绑定表单；绑定验证成功前不写入当前电脑地址。离线账号电脑不可选。
- 高级设置与解码器使用同一份当前配置档；页面渲染不初始化 JNI。画面尺寸由主机会话协商，实际调整走串流工具栏，不保留会被覆盖的无效编辑项。

## 按钮与主题

- 主按钮为实心，次按钮为描边，次要操作为文字按钮，危险操作为红色按钮。每屏至多一个主按钮。
- 停止服务、恢复旧版本、删除密码或绑定等操作需要二次确认。
- 禁用按钮使用语义色，不整体降低透明度；文字与背景对比度至少 3:1。
- 浅色和深色共用主题色、开关状态与弹窗尺寸规则，禁止以系统默认染色覆盖产品颜色。
- 可点的设备操作有清晰的文字颜色与背景；图标操作有可读名称、提示及至少 48dp 的平板触摸区域。
- 设置标签页保留键盘焦点、UI Automation 名称和选中模式。

## 功能保留

整理页面时按[功能保留清单](功能保留清单.md)核对视频、输入、音频、快捷键、诊断与兼容能力。已有设置和配置消费路径继续保留；上游实现仍在但入口尚未迁移的能力单独记录，不写成已经可用。交付链完成前不扩大页面改版范围。

## 诊断与帮助

- 首帧只显示一次；连接阶段使用 ms，刷新率用 Hz、帧率用 FPS。事件写明“连接后”，状态采样检查点写明“检查时”，避免相加误读。
- 零耗时阶段不占普通界面；缺分段时说明记录不完整。详细数字及内部字段仍可复制诊断，不更改计时采集。
- 只有一个采样时不写中位数、均值或范围。内部 mode 编号留在诊断数据中。
- 手册标题和正文使用不同字号与字重；默认文件目录建议为“下载/我控制”，保留用户已选目录。

## 验证边界

离屏渲染、隔离回归和编译通过属于本机验证。真机安装、系统栏、输入法、真实网络切换、读屏及串流需要另做安装验收；不得把本机修改写成已安装修复。
