# 安装器备份保留

2026-11-14，阶段103本机源码改动；尚未打包或安装。

正常升级的目录使用被备份版本及构建码、UTC时间命名，例如 `0.8.13.154-20261114T074012123Z/backup`。`Z` 表示UTC；同一毫秒重试时追加序号，避免覆盖。目录名描述升级前的程序版本，首次安装没有旧版时使用传入版本。

安装成功、服务启动且回滚指针提交后，才自动清理较早备份，默认保留两份：当前回滚指针所指的一份，加其余备份中最新的一份。恢复旧版成功后也执行保留策略；安装或恢复失败时保留现有备份，不启动淘汰。采用数量上限，不额外按30天清理，防止长期不升级时丢掉仅剩的回滚来源。

旧GUID备份仍可读、可回滚，且在确认产品标记与原安装路径一致后参与清理；不批量重命名旧备份。恢复旧版时产生的反向恢复快照仍使用GUID，因为恢复出来的旧版卸载器只认识这种名称。指针格式、完整文件哈希和产品归属校验继续沿用。

清理范围只包含受保护安装器目录内、能够确认属于当前安装位置的 `backup` 子目录。当前指针始终保留；指针损坏时跳过清理。目录链接、未知目录、其他产品或安装位置、事务里的其他文件均保留。清理失败只记日志，不撤销成功安装；遇到占用文件时保留产品标记，后续成功安装可再次尝试。无法确认或暂时不能删除的目录可能使数量暂时超过两份。

检查入口：`tests/installer-retention/Run.ps1 -ArtifactRoot <新的隔离目录>`。本轮只运行模拟文件事务、NTFS链接/占用检查和编译，没有操作真实安装、服务或备份；完整记录见父仓库 `reports/stage103.md`。当前已安装154和对应冻结发布包不包含本次改动，需下次打包安装后生效。
