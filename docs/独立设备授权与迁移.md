# 独立设备授权与旧绑定迁移

2026-11-14，0.8.13/153最初实现，阶段102电脑和平板已装154。单设备权限撤销/短码重新确认恢复、真实SYSTEM/DPAPI/ACL已核对；两设备隔离、原始媒体撤权直连与配对崩溃恢复仍未实测，见阶段102报告。

## 新设备与权限

手机/平板用短码申请，由电脑核对确认后取得独立的32字节随机凭据；电脑只保存摘要。凭据关联已核对的ClientId和设备名称，不接受请求中的任意名字作为认证身份。同一ClientId重新确认绑定会轮换凭据，旧凭据立即失效。不同设备分别管理主屏、副屏、文件、剪贴板接口权限；文件浏览、上传和删除仍沿用文件页的独立授权，不因勾选文件接口自动开放目录或删除。

设备列表只返回名称、作用域和状态等概要，不返回摘要、原始凭据或媒体证书。授权库由SYSTEM服务管理，以机器DPAPI加密，目录只授予SYSTEM和管理员；拒绝重解析路径、异常大小和格式。持久保存失败时不更新内存授权。阶段102已核实真实SYSTEM服务、目录ACL、机器DPAPI摘要库及服务重启后的单平板授权保留。

敏感操作有电脑端确认，管理命令仍要求安装者/管理员授权的本地管道。确认弹窗不是Windows再次身份验证，也不能阻止已能控制安装者桌面的远端通过桌面操作它；没有增加独立设置密码或操作系统重新认证。

## 媒体配对与撤销

独立凭据必须先关联规范化的公开X.509 DER证书，禁止另一ClientId占用已有证书。配对批准前持久记录当前媒体信任基线，握手后核对实际新增身份必须与预检证书一致；证书替换、撤权、取消或响应丢失均不能直接提交。失败先停相关产品引擎，再按UUID和证书摘要回收新增记录、恢复原enabled状态，保留其他设置。恢复记录在回收成功前保留，服务重启时必须先完成恢复才能启动引擎。

撤销独立设备或取消主/副屏权限后，HTTP请求立即重新校验；服务结束对应会话，并在确认引擎停止后精确清除该设备已关联的媒体证书。失败由监督任务及下次启动重试。不同凭据共享同一设备证书只允许经过同一ClientId重新本机确认的轮换；其他设备的配对不按名称猜测删除。

以上经过合成配置与内存API检查；阶段102单平板真实主/副屏握手及控制权限拒绝已测，绕开控制API的原始媒体撤权直连、服务崩溃恢复与两设备隔离仍待实机证明。客户端已持有的数据无法通过撤权收回；授权设备主动向第三方分享其私钥或凭据也不在单设备隔离保证内。

## 旧共享绑定

为避免升级后立即断开现有设备，旧共享绑定默认保留，并在电脑明确显示“旧版共享绑定”。它无法可靠区分控制端，不能显示为已认证的单台设备。先逐台用短码重新绑定，再由电脑关闭旧兼容。手工复制的旧邀请绑定码仍是共享授权。

关闭旧共享控制凭据不会自动清掉所有历史Sunshine媒体配对。新设备清单只管理已关联的证书，不能把未迁移的历史配对算作已撤销；应在原设备管理入口逐项核对清理。没有自动删除全部信任、替换TLS身份或上传安卓旧密码。

## 持续提示与通道说明

服务按活跃会话启动独立、不抢焦点的提示窗口，显示电脑确认的设备名称、粗粒度通道与断开入口；不依赖主窗口或托盘保持打开。154按用户要求在5秒后自动收起，隐藏后助手继续监测，同一设备连接不反复弹出，设备改变时重新短暂提示；托盘增加当前连接状态与断开入口。旧共享连接明确标为不能区分设备。当前按来源地址区分“异地安全隧道”和“局域网 / USB”，不能用它区分实际Wi-Fi与USB链路，也不能代替连通性测量。

提示位于普通交互桌面，Windows安全桌面未覆盖；154自动收起已由用户确认，服务崩溃回收与托盘新增断开点击未另测。隐私遮罩的实际品牌和恢复已由用户确认；仍保留原穿透、捕获排除和超时恢复逻辑。
