# UI 与构建维护

本轮日期：2026-11-20。仅修改本机源码，不升版本、不安装、不发布。

## 范围

本轮只做双端主题资源、公共控件、页面容器焦点框修复、隐藏冻结的电脑远程协助入口，以及安装器构建临时目录管理。没有改网络协议、串流引擎、绑定策略或文件访问权限。页面重排和新增功能留到下一轮。

主按钮仅使用三个固定蓝色：正常 `#2F70E0`、悬停 `#2D6CDD`、按下 `#285FC6`。对应白字对比度约为 4.65、4.88、5.93。禁止直接把正常主色继续调亮；调整必须重新核对最不利状态，普通文字最低 4.5:1。

卡片分界使用弱描边或底色；普通操作按钮的轮廓和文字统一使用主题蓝色`AccentText`，输入框使用中性控件轮廓色，轮廓与两侧相邻背景最低3:1。普通按钮按下文字使用`ActionPressedText`（浅色`#285FC6`、深色`#A3BFFA`），在按下底色上最低4.5:1；主按钮继续用白字，危险按钮保留危险色，禁用操作使用专用灰色。不要为了按钮边界把整页卡片描边一并加深。

悬停使用中性底色，选中使用浅蓝底及标记，键盘焦点使用外圈。焦点不得改变控件占位尺寸，也不得给整个页面容器画虚线。禁用态使用专用文字和底色，禁止降低整个控件透明度。安卓按钮最小点击高度保持 48 dp。

公共控件圆角 6–8，常规间距 8/12/16/24。本轮不重排页面、不恢复已删除的副标题。Windows 强制高对比度时优先使用系统色，不改用户保存的主题选择；关闭高对比度后恢复原选择。

2026-11-20阶段169追加：Windows界面不显示悬停说明；图标保留无障碍名称，读屏帮助和必要确认仍保留。设置行与布局容器不进入Tab顺序，焦点交给实际控件；设置标签、下拉选项的悬停底色同样采用圆角。文件设备选择在状态刷新时保留，文件页和权限页由同一选中身份同步，不用互相回写的双向绑定。

## 冻结入口

电脑远程协助页及侧栏入口隐藏；旧启动参数进入全部设备页。实现仍保留，未承诺协助链路质量已有改善。安卓远控、副屏和文件传输入口继续保留。

## 构建目录

- 每次生成独立 `package-时间-随机标识` 目录，写入所有权标记并在构建期间持有独占锁。
- 成功或失败都清理本次目录；文件占用时保留标记并报告失败，不伪报成功。
- 下次构建清理超过 24 小时的已标记孤儿目录，跳过运行中及显式保留的目录。不按文件名批量删除未知目录。
- 构建前检查构建盘与输出盘，默认最低可用空间 8 GiB；不足时停止并列出可检查路径。
- 最终安装器、源码、签名材料、冻结版本和回滚归档保留。共享下载缓存继续复用。

## 验证边界

Windows 使用隔离运行时和离屏渲染核对资源、状态和入口；安卓使用 Java/资源编译及隔离控件测试。它们不等于真机验收。完整安装器打包、正式升级、真机键盘流程、系统高对比度切换及完整 DPI 矩阵尚未执行。下一轮项目见根目录 `RELEASE_GATES.md` 的 2026-11-20 补充。
