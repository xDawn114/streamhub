# 177 本机缓存与首次预热

0.8.35/177为本机候选，电脑和平板最近实装仍0.8.34/176；手机最近核对168。177尚未安装、没有新增实机性能结论，Windows仍为手动引导安装准备，不算在线或0点击更新闭环。

持久探测缓存接入正式原生构建锁`streamhub.4.trace1.persist2`，沿用锁定的GCC 16.2.0 UCRT64、CMake 4.5.0及OpenSSL 3.6.5。新profile启用缓存并使用SDR自动计划；旧profile仅在引擎停止时补缺失项，保留显式关闭、完整计划、指定编码器和输出。兼容的窄提示不再因为重启而重写计划或改变指纹。配置、EXE、驱动、显示环境、计划或时效不匹配仍完整探测，命中也需实际H.264首IDR验证。

安装器使用原有主屏服务启动做一次预热，最多等30秒；读取原生真实就绪字段，不用“文件已存在”或“服务正在运行”代替完成。暂停、关闭主屏、活动会话和不可用状态均跳过或延后，不替用户恢复接收连接、不启动副屏、媒体会话或变更显示拓扑。预热未完成时首次连接仍可能走完整探测。

首次实机验收须核对正常安装时`encoder-prewarm-ready`记录、缓存文件生成与后续重启命中，以及暂停和无可用桌面时的延后记录。只在具体改动的同日交替对照或交付前测量；冷连门改为中位≤5000 ms、最慢≤5500 ms，热连10%退化必须有受控对照。历史样本不与本轮混算，不追溯把175的旧失败改为通过。完整口径见[首帧验收规则](首帧验收规则.md)。

本机检查覆盖配置迁移/幂等、显式关闭、兼容提示、缓存损坏/过期/变化、实际文件读写、重验失败删除与安装等待边界。GPU、真实首次连接及安装阶段预热仍须交付验收，不能把隔离回调检查当作显卡通过。176正常退出回FREE的修复保留。
