# 我控制图标

- 图标来源：`我控制-图标源.jpg`，使用用户提供的原图，保留白底和原始绘制内容。
- Windows：`我控制.ico`，含 16/24/32/48/64/128/256 px 多尺寸。
- Android：`client/artemis-src/app/src/main/res/mipmap-*` 下的 `ic_launcher.png` 与 `ic_launcher_foreground.png` 已按各密度生成。
- 自适应图标背景：`values/ic_launcher_background.xml` 使用白色以匹配原图。

WPF 项目设置 `<ApplicationIcon>Assets\我控制.ico</ApplicationIcon>`。
